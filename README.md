# ドイツ語 ゼロから完全攻略（Lektion 3 p.24 〜 Lektion 4 p.32）

単語も文法もゼロの状態から、教科書の **Lektion 3（p.24）〜 Lektion 4（p.32）** をスマホ・PCどこでも勉強できるWeb学習アプリです。

## 収録内容
- **Step 0：完全ゼロからの超入門**（名詞の性別 der/die/das、1〜4格の意味、定冠詞・不定冠詞、動詞の基本活用、語順、発音）
- **Lektion 3（p.24〜29）**：名詞の複数形、男性弱変化名詞、人称代名詞の3・4格、語順ルール、3格支配動詞、時刻表現、持ち物単語、Lesen 3『Mein Geburtstag』全文分解解説、縮小語尾 `-chen / -lein`、必須単語10個
- **Lektion 4（p.30〜32）**：不規則動詞の現在人称変化（`a→ä`, `e→i`, `e→ie`, 特殊動詞）、命令形（`du / ihr / Sie`）、提案表現（`動詞 + wir!`）
- **単語帳＆暗記カード＆4択クイズ**：性別カラー分け（青＝男性 / 赤＝女性 / 緑＝中性 / 橙＝複数）＋ドイツ語音声読み上げ対応
- **教科書演習（p.24〜32）ハイブリッド問題集**：4択モードとスペル入力モード（`ä ö ü ß` 入力ボタン付き）を切り替え可能。ヒント＆超丁寧な解説付き。

## GitHub Desktop を使って公開する手順（GitHub Pages）
1. **GitHub Desktop** を開く
2. 左上 `File` → `Add local repository...` を選び、この `german-study-web` フォルダを選択
3. 右上の **`Publish repository`** をクリックしてGitHubにアップロード（※公開URLを作るには `Keep this code private` のチェックを外して Public にする）
4. ブラウザでGitHubの自分のリポジトリを開く
5. 上のタブ **`Settings`** → 左メニュー **`Pages`**
6. `Branch` を **`main`**、フォルダを **`/ (root)`** にして **`Save`**
7. 1〜2分待つと `https://21bebe.github.io/（リポジトリ名）/` のURLが発行され、スマホでもどこでも勉強できるようになります！
